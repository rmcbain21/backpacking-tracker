# Categories belong to each Gear List, copied from Default Categories

A Category ("Big Three + Sleeping Pad", "Food and Water") is part of one Gear List or Packing List, not of the Gear Item, and each List Entry picks its Category on that list. A new Gear List starts with a copy of the backpacker's Default Categories; after that its Categories are its own, so renaming "Big 3" to "Big 5" on one list changes no other list, and changing the Default Categories later changes no existing list. What a Gear Item *is* (Backpack, Tent) is its Gear Type instead. This matches how the backpacker's trip sheets work: each sheet arranges the same gear into its own sections, and the same backpack can sit under different sections on different trips.

## Considered Options

- **One Category per Gear Item** (the first version): rejected; it mixed "what the gear is" with "how this list is arranged", so a trip sheet's sections overwrote the gear's grouping.
- **One shared set of Categories that every list picks from**: rejected; renaming a section for one trip would rename it on every list and past Trip.

## Consequences

- Comparing trips by Category is by name only: "Food and Water" on two lists are two separate Categories that happen to share a name.
- Duplicating a Gear List, or creating a Trip from one, copies its Categories along with its List Entries.
