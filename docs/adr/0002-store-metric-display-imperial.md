# Store metric, display imperial

All weights are stored in grams (to 0.1 g) and all distances and elevations in metres, even though the app shows imperial units by default. One unit per quantity keeps weight totals simple and free of lb/oz conversion, outside sources (manufacturer specs, food databases, GPX files) are metric, and changing the display unit never touches stored data. Don't "fix" the stored values to ounces or miles.
