# 04: Categories

**What to build:** Every Gear Item belongs to exactly one Category. On first run I get a sensible default set, and I can add, rename, reorder and remove my own. I can filter my gear by Category.

**Blocked by:** 01 (Walking skeleton)

**Status:** ready-for-agent

- [ ] On first run, default Categories exist: Shelter, Sleep, Pack, Cook, Water, Clothing, Electronics, Hygiene, First Aid, Misc.
- [ ] I can add, rename, reorder and remove Categories.
- [ ] Removing a Category that Gear Items use is refused unless I choose another Category to move them to.
- [ ] Adding or editing a Gear Item requires choosing a Category.
- [ ] The gear page groups or filters Gear Items by Category, in Category order.
- [ ] Core tests cover defaults, rename, reorder, and the remove guard and move.
