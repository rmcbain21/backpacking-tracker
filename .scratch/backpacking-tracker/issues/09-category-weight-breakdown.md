# 09: Category weight breakdown

**What to build:** On a Gear List I can see how its weight splits across Categories, with each Category's weight and share of the total, so I can see where my weight goes.

**Blocked by:** 04 (Categories), 08 (Gear Lists and weight totals)

**Status:** ready-for-agent

- [ ] The weight calculator returns a breakdown by the Gear Item's Category, with weight and percentage share, in Category order.
- [ ] Categories with no entries on the list are omitted.
- [ ] The Gear List page shows the breakdown (a simple table or bar is fine on phone).
- [ ] Core tests cover the breakdown sums and shares.
